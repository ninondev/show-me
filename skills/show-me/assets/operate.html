What can it learn?

Literal replacements, prefixes and suffixes, case changes, outer-space trimming, and splitting words on spaces, slashes, underscores, dots or hyphens. It searches these operations locally. Use examples to distinguish rules that produce the same result on one record.

JSON records need a unique string id and a string in the chosen text field. Other fields are preserved. Limits: 1,000 records, 4,000 characters per text field and 2 MB per file. An exported operation contains its literal replacement text; review it before sharing.

Runs locally · No accounts, model calls or remote libraries
